# Dockware NVIDIA System Cards

System Cards for Dockware products, prepared using the [NVIDIA Trustworthy AI System Card](https://github.com/NVIDIA/Trustworthy-AI/blob/main/System%20Card) template (Creative Commons Zero).

| Product | Card | Role |
| --- | --- | --- |
| **Vision** | [Vision-System-Card.md](Vision-System-Card.md) | Dock-mounted autonomous freight sensing |
| **Scan** | [Scan-System-Card.md](Scan-System-Card.md) | Handheld iOS/Android shipment capture |
| **Portal** | [Portal-System-Card.md](Portal-System-Card.md) | Outdoor fixed truck/rail passage inspection |

Cards are written for external sharing (e.g., NVIDIA Inception): capabilities, risks, and hardware class only—without proprietary model, middleware, or pipeline internals.

Based on the [NVIDIA Trustworthy AI System Card](https://github.com/NVIDIA/Trustworthy-AI/blob/main/System%20Card) template.
